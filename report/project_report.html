3. Git & GitHub Version Control Pipeline

3.1 Version Control Methodology (IT4048 Core)

Version control is the engineering discipline of managing and tracking changes to software source code over time. For this mini-project, Git was utilized to manage the codebase from ground zero through incremental feature additions, refactorings, asset integrations, and remote publishing.

3.2 Commit History & Semantic Conventions

To ensure professional traceability and maintain an audit log, commits follow the Conventional Commits standard. Every commit message explicitly declares its category, scope, and intent:

  • feat(structure): initialize semantic HTML5 portfolio foundation
  • style(design): implement retro dark theme with glassmorphism and CRT overlays
  • feat(3d): integrate Three.js wireframe geodesic sphere and dust particle field
  • feat(cursor): implement celestial star sparkle and golden ribbon trail canvas
  • feat(personalize): bind Nidhi Patel academic profile, LinkedIn, GitHub, and email
  • docs(report): generate academic project report and submission documentation

3.3 Deployment Pipeline (GitHub Pages)

The application leverages GitHub Pages for continuous static delivery. The end-to-end workflow operates as follows:

Continuous Deployment Pipeline Flow:
Local Workspace → Git Staging (git add) → Semantic Commit (git commit) → Remote Push (git push origin main) → GitHub Pages Automated Build Worker → Live Global HTTPS Distribution at:
